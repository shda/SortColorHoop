# SortColorHoop

Это мобильная и браузерная головоломка, в которой пользователю предстоит сортировать разноцветные кольца по стержням на подставках, применяя различные бонусы и стараясь собрать на каждом из стержней набор колец одинакового цвета. С каждым пройденным уровнем сложность игры будет возрастать, и игроку придется взаимодействовать с большим количеством стержней и колец различных цветов.
